# Capturas para las vistas previas premium

Coloca aquí, manualmente, las capturas de Android. No es necesario registrarlas
como recursos `drawable`: la vista previa las carga directamente desde `assets`.

Se admiten las extensiones `.png`, `.webp`, `.jpg` y `.jpeg` (en ese orden de
preferencia). Conserva exactamente el nombre y la capitalización indicados:

- `agenda`: `Agenda_1` a `Agenda_5`
- `centro_sanador`: `CSanador_1` a `CSanador_6`
- `ciclo_consciente_diario`: `Ritual_premium_1` a `Ritual_premium_5`
- `coherencia_cardio_cerebral`: `CC_1` a `CC_4`
- `espacio_calma`: `EspacioC_1` a `EspacioC_6`
- `inteligencia_artificial`: `IA_1` a `IA_4`
- `lienzo_creativo`: `Lienzo_1` a `Lienzo_4`
- `metas`: `Metas_1` a `Metas_9`
- `presencia_consciente`: `Presencia_1` a `Presencia_3`
- `protocolo_transformacion`: `ProtocoloTrans_1` a `ProtocoloTrans_3`
- `recordatorios`: `Recordatorios_1` a `Recordatorios_3`
- `revision_semanal`: `ResumenSemanal_1` y `ResumenSemanal_2`

Mientras una captura declarada no exista, la app muestra un marcador visual en
su lugar. Las carpetas sin nombres en esta lista corresponden a presentaciones
que no necesitan galería, igual que en iOS.
